## 1. 最新用戶指示與編劇工作方法
- **先完成第一集作為原型，暫不推進第二、第三集**。第一集範圍是母稿**第一至六節**：序章送藥→火災→鎮長私談→守衛室→艾倫→帳房／老倉丁→米拉→議事廳→發現北路糧車線索→準備出發。
- 使用者自己改寫敘述、節奏、修辭；**用使用者的最新文字作基準**，不要拿 Agent 舊稿覆蓋。使用者偏好像小說的對話、具體場景與暗示，不要旁白解釋心理、不寫「你察覺自己受到攻擊」等破梗解說。
- **一名玩家只會閱讀自己走過的一篇小說**。各分支必須在玩家未閱讀其他路線的情況下，自成完整、人物合理、資訊連貫的故事。不能只寫四段短反應再無條件忘掉前文。
- **第一個選擇即形塑主角的性格起點**，後續選擇要在其性格範疇內延續，或透過可感知的事件逐步轉變；不能無理由性格翻轉。編劇需要同時追蹤「世界事實／人物知道什麼」「守衛性格」「與他人關係」「可見線索」「延遲後果」。
- 不把主角性格固定成好壞四型或心理測驗。初始四向：A 說明／重視事實；B 反擊／自主抗衡；C 救火／務實行動；D 沉默／觀察保留。不同起點仍可選擇同一種助人行動，但表現方式、台詞、出發理由應有所不同。
- **固定世界事件，不固定人物體驗**：全部路線都走向「去找那輛車」，但動機及同行三人關係不同。原著四種離城理由尚未在可玩遊戲中真正落成獨立文本；編劇地圖尾聲的四個節點是待創作，不要誤稱已實作。
- **玩家面前不講課、不說教、不揭示罪咎主題**。內部可用「受害、恐懼、防衛、罪咎、無能為力、沒得選」規劃，但它們只能透過人物與事件讓玩家自己體驗。整個故事的終極母題是「有人犯錯，未必有壞人」，不是由作者直接宣布。

## 2. 世界觀與不可違反的事實（劇情真相 ≠ 玩家已知資訊）
- 虛構城鎮「霧谷」，連日大雨、糧倉失火，存糧原配給約五天。
- 主角是當夜值守的守衛。九點報時鐘剛過，醫師請他到東門外棚子送藥給鎮長發燒的小兒子；醫師還在替另一名病人縫傷口。鎮長知道醫師派守衛送藥，**但不知道主角離開及返回的精確時間**，也在隱瞞孩子發燒以免居民恐慌。守衛簿只寫「九點離崗」，事由未填。主角出門前把缺角的糧倉**側門鑰匙**掛回守衛室左起第二銅鉤。送到藥時，**警鐘**響三聲；報時鐘與警鐘務必區分。
- 艾倫聽到火警後到守衛室拿走**側門鑰匙**，到火場打開側門救人，鑰匙遺留鎖孔。手受燒傷。他害怕被指控與擔責，尤其還欠糧商賀維一副車架的賠償。
- 糧倉的**帳房隔離厚門之門閂**與側門鑰匙是**不同裝置、不同門**：側門鎖舌正常、需鑰匙；帳房與糧區之間的隔離門門閂／釘腳已損壞，因修繕延誤而不能有效關閉。**不要再把兩者混為一談**。
- 白天糧商**賀維**運貨時，因道路泥濘、車太重，先把燈油暫放進糧倉帳房，準備回程再取，明知大量油料不應入倉但以為安全。**老倉丁白天接待並知情**，失火後因害怕擔責而隱瞞油桶來歷。賀維**第一集不正式出場**，直到後續找到受困糧車才現身。
- 米拉是 15 歲糧倉學徒，被老倉丁公開責罵過，怕帳目七行未完成又被罵，夜裡偷偷拿**正門鑰匙**入帳房補帳；她**不知道白天有油桶搬入，也沒目睹卸油過程**。摸黑進去撞到桶子，以為是空桶；燈翻倒，沾油粗布助長火勢，她受傷，無法完整解釋油桶來歷。她的認真既促成冒險犯錯的情境，也令她在後續記住運單與貨物。
- 艾倫注意到一輛往北走、尾端綁**藍繩**的貨車；米拉查入倉簿認出「快馬號」曾卸 **18 袋**麥糧給霧谷，貨車另載 **32 袋**準備送石溪村。最初只能推測貨車仍在北路及可能載糧，不能在第一集查明其位置、賀維責任或後來分糧決定。
- 第二、三集尚待開展：北路因雨受阻，三人終找到糧車；賀維初先辯解並堅守石溪村的貨物所有權，返回霧谷議事廳後才在看見危機與需求時轉向適切回應，與石溪協調分糧，不是單純「內疚所以拿別人的糧贖罪」。使用者原稿有後續詳細事件，但**現在不改寫第二、三集**。

## 3. 第一集分支結構與性格軸
首節火場 `fire` 的選擇：
- A `fire_plain`：「放火的不是我。我是替醫師送藥。」——重視可查證的說明／希望被理解。其後醫師一事應由**旁觀居民**質疑，鎮長已知送藥，不應明知故問。
- B `fire_fight`：「你憑什麼說是我？你自己不是也有鑰匙？」——反抗指控／不願讓權威獨佔解釋。居民替鎮長說他當時在家安撫兒子，無意觸及他想隱瞞的病情。
- C `fire_rescue`：「救火的人還在裡面，現在要先吵這個？」——行動回應當下需要，不可自動定義他在贖罪；是否有防衛應由後續劇情展現。
- D `fire_silence`：不當眾回答，先看鑰匙——觀察、審慎、可能不擅當眾爭辯；亦不可自動定義為怯懦。
四條都突顯鎮長的秘密與守衛百口莫辯，但**必須有各自延遲後果**：不同居民證詞、鎮長互信、火場證人與證物、沉默造成的流言等；同時安排各自的收穫與代價，避免四條路都只有「受害更深」。
其後主要節點：`mayor` 鎮長私談→`guardroom` 守衛室→`well` 艾倫→`granary` 現場→`keeper` 老倉丁→`mill` 米拉→`mira_after` 是否代米拉說→`hall` 議事廳→`cartclue` 貨車線索→`departure` 出發→`finish`。共 **11 組需要選擇的場景**，多數四選一；遊戲源碼已有 54 個節點，編劇地圖規畫 **58 個節點**（多 4 個尚未編寫的出發性格支線）。
四條出發動機仍**待正式編劇**：重證據者去查明、反擊者想掌握主動、行動者看到缺糧急迫、觀察者願親自走一趟。不要在玩家文字直接寫「你是說明型」「你想贖罪」等性格／心理宣判。
**若設計改變分支數量**，需一併檢查目前短承接碼、選擇紀錄及第二集回放邏輯，不能只改文字。

## 5. 體驗與文字寫作準則（不可破梗）
- 使用者親修語氣：以自然口語、短促緊湊的對話、具體因果、人物立場與資訊落差推動戲劇；衝突高點立即切選擇，不要補「你愣住了，你不是縱火者」等代替讀者理解的旁白。
- 場景調度需可信：糧倉仍起火，居民仍忙著打水、搬糧；每個配角有動機、知道的範圍和實際正在做的事。**人物只能依照自己當時知道的資訊說話，不可用作者掌握的全貌說話**。
- 守衛、鎮長、醫師、米拉、老倉丁、艾倫、賀維的行為前後一致。尤其鎮長早知送藥但未知精確行蹤；原稿因「明知故問」曾被使用者指出，已由旁人提問修正。
- 「罪咎、受害、無能為力、沒得選」是內部設計核心，但人物不被判定為壞人；行為失誤仍有後果、需要修正。情緒骰子用於擴充玩家觀看角度，不替玩家選哪條路。
- 插畫的先前三張畫風為低彩度、石墨鉛筆與墨彩的文學插頁；後兩張曾畫風不一致，已重新替換。保持角色、道具、場景前後一致，避免拼貼圖充作獨立插圖。
- 「更多選項」不等於「更好的選擇」：每個選項應有可追溯的後果，並保持故事流暢。玩家只讀到自己路徑的一篇小說，故事不能依賴他知道未讀的支線。

## 6. 下一個 Agent 的具體工作
1. 首先到 GitHub 拉取 `fog-valley-story-map.html` 與 `fog-valley-episode-1-v2.html` 最新版，閱讀本備忘錄和使用者修訂的 Google Drive 小說母稿。
2. 若用戶已在瀏覽器編劇地圖填寫新稿，先請其**匯出 JSON**，不要覆蓋尚未上傳的本機修改。
3. 逐節修整四種守衛性格的弧線；以目前 `fire` 四條及 `mayor` 為起點，把艾倫、老倉丁、米拉、議事廳、尋車動機的文案與狀態延遲後果銜接完整。每節要記錄：人物性格、衝突、其他角色互動、知道的線索及不能破壞的事實。
4. 對各主要路線做**「只看當條路線」的連續閱讀審核**，不可只檢查單頁文字或程式不報錯。
5. 等使用者確認文字後，才把編劇地圖定稿同步回可玩 HTML，再測試骰子、插畫、存檔、承接碼與手機畫面。
